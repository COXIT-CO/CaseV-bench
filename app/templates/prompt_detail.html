Run configuration

System prompt

User prompt

2-pass: pass 1 finds elevations on the full sheet; pass 2 crops each elevation from the original image and looks for cabinets/countertops separately at higher resolution. Uses roughly 1 + one request per elevation found on the sheet.

Tiled: cuts the full-resolution page into a grid of overlapping tiles and runs the same full prompt on every tile independently, then merges and deduplicates detections found in more than one tile.

Expected JSON

Either a counts object {"cabinets": 5, ...} (compared by count), or — for locate/locate_2pass — a list of ground-truth boxes for IoU scoring: [{"object_type": "cabinet", "bbox": [left, top, right, bottom], "page": 0}, ...]. bbox must be normalized 0..1000 (same scale as detection boxes, not 0..1), and page is 0-based to match the processed page order (first page = 0).
