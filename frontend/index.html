Two-Stage Detection

Single model · human-reviewed

Stage 1 finds elevation frames AND elevation_callout symbols on every page of every uploaded PDF, in one pass — callouts live on floor plans/RCPs and need no review, so they're carried straight through. Review and uncheck any elevation that's wrong (per page), then Stage 2 re-renders each reviewed page from the original PDF (at its own DPI) and crops each approved elevation out of that render, asking the model for cabinet and countertop within it. The final result is drawn back on the full pages, in the same JSON format as a regular benchmark run. Every page is still sent as its own request — Execution Settings only controls whether those per-file/per-page requests run one after another or at the same time.

Grid Detection

Grid cells, not coordinates

A labeled reference grid (columns lettered "A", "B", ... left-to-right, rows numbered "1", "2", ... top-to-bottom) is drawn on the page before it's sent — each model reports which cell(s) an object occupies (e.g. "cells":["B2","B3"]) instead of estimating a numeric box, and the box is derived from those cells in code. Exactly ONE PDF at a time — ground truth is entered below for this specific document, so results are scored per page with location-scorer as soon as the run finishes.

Cell labeling

How cells are named — and what the model is told to name them — without touching the System Prompt: this is layered onto whichever prompt is configured, per request.

Box precision

By default a detection's box is the full outer edges of every cell it named. "Cell + anchor" tells the model it MUST also say where WITHIN its start/end cell the object's own corner sits, picked from 9 fixed positions (a corner, an edge midpoint, or the center). "Cell + 0-1 point" instead requires a free [fx, fy] coordinate inside that cell — more flexible, but a harder estimate for the model to make. Both modes are phrased as required, not optional, since models otherwise default to the cell's outer edges out of habit; if the model still omits it, the full cell edges are used as a safety net, same as today.
